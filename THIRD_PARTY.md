# Sources and bundled components

Navigation/action icons and the Nexus Companion crystal mark in `assets/ui` are original geometric artwork generated by `make_ui_icons.py`, not Blizzard logos. Hero portraits remain Blizzard game artwork as credited below; the application is unofficial.

- Hero portraits: Blizzard game art distributed by [HeroesToolChest/heroes-images](https://github.com/HeroesToolChest/heroes-images). Draft and square hero-select portraits are used locally to compare draft ban icons; no screenshots are uploaded. Test fixtures retain only ban-icon strips from user-supplied screenshots, without player labels or chat.
- Collection exporter: [spazzo966/HeroesOwnedItemsInterface](https://github.com/spazzo966/HeroesOwnedItemsInterface), release v1.1, `HeroesOwnedItems.StormInterface`. Use in replays only; never as a live observer interface. The app copies the file only when you select a destination; it does not modify game settings.
- Free rotation: [Nexus Compendium API](https://nexuscompendium.com/api/). Requests contain no account, collection, draft or screenshot data.
- Talent selections: [Icy Veins](https://www.icy-veins.com/heroes/), 90 public hero build guides, imported 2026-09-19. `build_catalogue.json` records 292 named builds, factual talent choices and alternative names, source URLs, each guide's stated update date, and the import date. Guide prose is not bundled; short coaching tips and matchup rules are independently written for Nexus Companion. Research HTML in `.guide-cache` is not app content and should not be distributed. Builds do not refresh with game patches automatically. Each hero's guide opens through the app's source button.
- Local recognition: Windows OCR, PyWinRT, Pillow, NumPy and OpenCV. Installed package metadata and licenses are in `.deps`.
- Draft relationships: the same 90 [Icy Veins hero guides](https://www.icy-veins.com/heroes/), imported 2026-09-19 into `draft_catalogue.json`. Stores named synergy and directional counter listings and map categories, with per-hero source/update/import metadata. These are guide opinions, not win-rate measurements. Guide prose and strength/weakness paragraphs are not copied. Scoring weights, composition rules and explanation text are authored for Nexus Companion. `import_matchups.py` is a maintainer-only extractor from the guide cache.
- Background capture: [windows-capture](https://github.com/NiiightmareXD/windows-capture), using Windows.Graphics.Capture. Only the verified HotS window is targeted; no screen-wide fallback is used.
- Blind mechanics reference: [Li Li abilities and strategy](https://www.icy-veins.com/heroes/li-li-abilities-strategy). Named opponent priorities are local coaching rules, not live enemy talent detection.
- Replay results: [Blizzard/heroprotocol](https://github.com/Blizzard/heroprotocol), MIT, version 2.55.4.91756; [mpyq](https://github.com/eagleflo/mpyq), version 0.2.5; six 1.17.0. Package metadata/licenses are in `.replay-deps`. Unmodified protocol modules are loaded with importlib for Python 3.14 compatibility. Self-describing header/details records are validated for participating account, hero and consistent team results. Newer game-mode layouts are used only after identity/team/slot checks against details; otherwise mode remains Unknown. ARAM's lobby hero placeholders are not treated as final hero selections.
- Replay field reference: [Stats of the Storm's replay data reference](https://ebshimizu.github.io/stats-of-the-storm/hots-replay-data.html). Only local summary fields are retained; no chat, event stream or replay uploads.

Nexus Companion is an unofficial local tool, not affiliated with Blizzard, Heroes Profile or these community projects.

The Windows distribution includes the CPython runtime and its license under `licenses/python`, and the PyInstaller bootloader (license and bundling exception under `licenses/pyinstaller`). Runtime-package license/metadata directories are bundled under `licenses`; replay-package notices are retained under `.replay-deps`. Inno Setup is used to produce the installer. Builds are checked through published project releases; the app does not scrape guides during play.
